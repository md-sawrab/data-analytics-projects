# Tea Consumer Behavior Analysis

## Consumer Preference and Buying Behavior Toward Packaged Tea Brands in Bangladesh

This project analyzes consumer preference, purchasing behavior, satisfaction, and brand loyalty toward packaged tea brands in Bangladesh using SPSS statistical techniques.

---

# Project Overview

The main objective of this project was to generate consumer insights for the FMCG industry by analyzing tea consumers’ purchasing patterns and brand preferences.

The analysis focused on:
- Consumer demographics
- Preferred tea brands
- Purchase frequency
- Customer satisfaction
- Brand loyalty
- Advertisement influence

---

# Dataset Information

- Total Respondents: 250
- Dataset Type: Structured consumer behavior dataset
- Industry: FMCG (Tea Products)

### Variables Included
- Gender
- Age Group
- Occupation
- Monthly Income
- Preferred Tea Brand
- Purchase Frequency
- Buying Place
- Advertisement Influence
- Price Sensitivity
- Taste Satisfaction
- Packaging Satisfaction
- Brand Loyalty
- Recommendation Intention

---

# Statistical Analyses Performed

The following analyses were conducted using SPSS:

- Frequency Analysis
- Descriptive Statistics
- Crosstab Analysis
- Chi-Square Test
- Correlation Analysis
- Independent Sample T-Test
- One-Way ANOVA
- Reliability Analysis (Cronbach’s Alpha)

---

# Key Findings

- Ispahani was the most preferred tea brand among respondents.
- Most consumers purchased tea daily or weekly.
- Local stores were the primary purchasing channel.
- Taste and packaging satisfaction showed strong positive relationships with brand loyalty.
- Advertisement influence positively affected recommendation intention.
- Gender and income groups did not show statistically significant differences in brand preference and loyalty.

---
